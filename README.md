2. Why is a perfect fingerprint recognition system impossible?

A perfect system is impossible because two scans of the same finger are never exactly the same (position, rotation, pressure, dryness). So genuine and impostor scores can overlap, and any threshold gives some false matches or false non-matches.

3. Where could fingerprint recognition be used, and what could go wrong?

It could be used for phone unlock, door access or border control. It could go wrong if a genuine user is rejected by a dirty or partial print, or if a fake fingerprint is accepted.
